## Primary route: comparable full-score refits

Use 2025/26 GW28–38 as the proposed common evaluation window. Defensive-action
history exists before it, avoiding a future-trained DC estimate in early weeks.
The initial panel is an incumbent-method reference and, when their feature inputs
are independently audited, Dastan and OpenFPL-method references. Name each refit
explicitly; none is the original stored/deployed model binary.

- Training: completed seasons2020/21–2024/25 plus2025/26 GW1–19.
- Validation/calibration/early stopping:2025/26 GW20–27, never GW28–38.
- Test:2025/26 GW28–38; full actual points under2025/26 rules, next-GW horizon.
- Freeze the exact eligible fixture rows and per-GW deadline timestamps from
  checksum-verified sources before fitting. No input may use a result at or after
  that deadline. Postponed fixtures must be assigned by actual predeadline data,
  not final schedule hindsight.
- First pilot: one fixed seed, fixed published/reference hyperparameters, no
  search. Training parameters use the training period only; validation may select
  iterations/calibration as declared by each method. Do not refit on validation
  for this first common-window pilot. The incumbent DC component likewise uses
  training-only observations, with validation-only selection if required.
- Lock component targets, allowed features, seed, transformations, candidate
  predicate, calibration, source revisions and resource budget in an immutable
  run manifest before launching. Fail readiness rather than silently dropping
  unavailable seasons/features or changing the training regime.
- Reconcile exact full-score outcomes and stable IDs for every method; use the
  predeadline candidate pool as primary and all-player scores as secondary.
  Native-feature results compare whole methods. Common-feature ablations are
  separately named experiments.

This expands beyond the original incumbent annual fit and may differ from
external published training policies. Results must be called common-window
retrospective reference fits, not original-system scores. Feature audit and a
resource-controlled fit are prerequisites; no accuracy score is available yet.
If the external source cannot reproduce this regime, report that method ineligible
and explicitly revise/version the plan before fitting, not after viewing scores.
