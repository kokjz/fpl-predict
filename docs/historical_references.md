# Historical external references

`fpl-predict historical-references prepare --help` lists explicit private input
paths. Preparation audits hashed raw histories and previously frozen reference
outputs, then freezes the comparison policy and legal fixed squads. It performs
no model fitting. `run --manifest MANIFEST --manifest-sha256 SHA256 --directory
NEW_DIRECTORY` verifies that lock before serial independent fits and aggregate
scoring. Use the existing resource supervisor around the run. No network access,
account operations, workspace initialisation, automatic promotion or scheduling.

Install the optional `reference` extra only in an isolated research environment.
Ordinary forecasts and command help need no XGBoost installation. Raw histories,
private row predictions, resource logs and manifests are not public repository files.
Read [the frozen protocol](HISTORICAL_EXTERNAL_PROTOCOL.md) before use. The two
named adaptations compare methods under explicit reconstruction assumptions;
they do not certify the original providers' historical live performance.

`fpl-predict archived-reference --help` exposes a separate read-only adapter for
a published `frozen_official_forecast_v1` player-GW CSV. Supply its original
manifest, saved local forecast, original bootstrap identity bridge and finalised
official outcome snapshot. It verifies the CSV checksum/count/season/GW, stable
codes, positions, generation/source times and both forecasts' predeadline status.
Every saved local prediction needs an outcome history; missing exports are reported
as coverage, never filled with invented predictions. Output includes aggregate
metrics and source hashes, not team selections. Different information cutoffs and
publisher-declared clocks/training remain explicit; one GW supplies no uncertainty
interval or season ranking. Archive comparisons do not initialise or modify the
private runtime, historical forecasts, trial designations or approved registry.

The [dated results](HISTORICAL_EXTERNAL_RESULTS_2026-10-15.md) and
[source admission table](EXTERNAL_MODEL_ADMISSION_2026-10-15.md) record what was
actually run, the measured resource cost and the remaining original-system limits.
